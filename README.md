# Auto MPG Data Analysis Assessment

## Overview

This repository contains my Python for Data Analysis assessment, based on the **Auto MPG dataset**. The assessment focuses on applying NumPy, Pandas and Matplotlib to perform numerical computations, data manipulation, statistical analysis and visualization.

The dataset contains specifications and fuel efficiency information for 398 automobiles from model years 1970 to 1982.

## Technologies Used

- Python
- NumPy – Numerical computing and array operations
- Pandas – Data manipulation and analysis
- Matplotlib – Data visualization
- Jupyter Notebook – Interactive development environment

## Assessment Structure

The assessment is divided into three main sections:

### Part A – NumPy Problems

10 exercises covering:
- Basic array operations and statistical calculations
- Array filtering and Boolean indexing
- Percentiles and normalization
- Broadcasting and missing-value handling
- Matrix operations and dot products
- Sorting and correlation analysis
- Conditional aggregation

### Part B – Pandas Problems

10 exercises covering:
- Data exploration and summary statistics
- Filtering and indexing
- Missing-value treatment
- Data transformation and feature creation
- GroupBy operations and sorting
- Applying custom functions
- Data export and anomaly detection using IQR

### Part C – Matplotlib Visualizations

10 exercises covering:
- MPG distribution using histograms
- Boxplots and scatter plots
- Correlation and trend-line visualization
- Fuel efficiency across model years
- Car distribution by origin
- Acceleration comparisons
- Three-dimensional scatter plots
- Top 10 fuel-efficient cars

## Dataset Information

The Auto MPG dataset includes the following attributes:

| Feature | Description |
|---|---|
| mpg | Miles per gallon |
| cylinders | Number of engine cylinders |
| displacement | Engine displacement |
| horsepower | Engine horsepower |
| weight | Vehicle weight |
| acceleration | Acceleration time |
| model_year | Model year |
| origin | Country of origin |
| car_name | Automobile name |
